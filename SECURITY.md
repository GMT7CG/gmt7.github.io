# Security policy

## Supported versions

This repository is a static brochure site with no server side code and a single
deployed version (main branch, GitHub Pages). Only the latest commit on `main`
is supported.

## Reporting a vulnerability

Please report security issues using GitHub's private vulnerability reporting
feature on this repository: open the "Security" tab, then "Report a
vulnerability". Do not open a public issue for security reports.

We will acknowledge new reports and aim to provide a status update within
30 days.
